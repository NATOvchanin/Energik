# Мистер Энергик

Оффлайн голосовой ИИ-кореш для ПК и стримов: дерзкий соведущий, который слушает, отвечает
роботским голосом, помнит контекст и (позже) видит экран.

## Этап 1: уши и голос

Говоришь в микрофон, Энергик распознаёт речь и повторяет её роботским голосом.

### Установка (Windows, Python 3.11)

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python check.py
```

### Запуск

```
python voice_lab.py      # послушать пресеты голоса, выбрать на слух
python main.py           # режим «повторюшка»
python main.py --devices # список микрофонов и колонок
```

Все настройки (микрофон, модель Whisper, голос, пресеты роботизации) лежат в `config.toml`.
Модели скачиваются сами при первом запуске и в репозиторий не попадают.
